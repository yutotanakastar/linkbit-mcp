# Security Policy

## Reporting a vulnerability

Email **youdododododo@gmail.com** or open a private report on GitHub.

Please include:

- What the issue is
- Steps to reproduce
- Impact (for example: unauthenticated access, open redirect, key leak)

Do not file public issues for secrets, auth bypass, or Safe Browsing / abuse-bypass bugs.

We aim to acknowledge reports within a few days.
